Start Mining

Works on any GPU — AMD, NVIDIA, Intel, Apple Silicon

1

Install

Python 3.8+ and a GPU. Install the miner:

cd miner
pip install -r requirements.txt
python voidmap-miner.py --detect
2

Run

Auto-detects the best GPU backend (CUDA, ROCm, MPS, OpenCL, or CPU).

python voidmap-miner.py \
  --address 0xYourWallet \
  --rounds 100
3

Earn

Each verified submission earns VOID tokens proportional to your data quality score (0-100). Higher quality = higher rewards.
