Core Mechanics

Six Invariants of the Protocol

The protocol is fully autonomous after mainnet launch. These six mechanisms enforce the rules in code — no human in the loop.

01 / HALVING

Bitcoin-Style Halving

Block reward starts at 50 VOID and halves every 210,000 submissions. Floor at 0.1 VOID. Total supply is capped at 1,000,000,000 and enforced in MiningPool.sol.

02 / ELASTIC MINT

Self-Balancing Elastic Mint

Reward scales with rolling 10-submission quality average. Target quality = 75. High quality dampens issuance (0.8×); low quality boosts it (1.2×). Dead zone ±5 prevents oscillation.

03 / CHALLENGE / SLASH

Verifiable Honesty

Any miner can challenge a submission within 6 h by staking 1 VOID. Submissions with quality below the floor are slashed 20%. Bond is split 50/50: half burns, half pays the challenger.

04 / TIME-LOCK

7-Day Governance Delay

Parameter changes queue for 7 days before execution. Proposers must stake 1% of miner-minted supply. No admin keys, no emergency switch, no pause().

05 / ANTI-ASIC

5-Layer Defense

Real data pipeline · dynamic ML models · 2 s compute attestation · FPGA/emulated GPU detection · architecture rotation every 100 blocks. ASICs cannot win this race.

06 / POOL PROTOCOL

Permissionless Pooling

Anyone may run a pool. 2% operator fee deducted at submission. Members tracked by share. Operator withdraws accumulated fees anytime via withdrawPoolFees().

Start Mining → Full step-by-step guide

Three commands. Any GPU. From zero to first VOID in five minutes.

① Test Mode (no wallet)

Run inference against the live data pipeline. No on-chain submission. Pure local computation.

# One command — multi-backend auto-detect
pip install voidmap[all]

voidmap-detect
voidmap --task exoplanet --rounds 3

② Submit to Testnet

Base Sepolia. Real contract calls. Get test VOID into a test wallet.

# Fund with Base Sepolia ETH, then:
export VOIDMAP_PK=0x...
voidmap-mine --task exoplanet --rounds 5 --submit \
  --rpc https://sepolia.base.org

Smart Contracts

On-Chain Protocol

Three contracts. Fully verified on BaseScan. No upgradeability. No admin keys. The token and pool are ownerless from block zero.

VoidmapToken ERC-20

  • → 1B fixed supply, 18 decimals
  • → 900M (90%) minted to miners via mintMinerReward()
  • → 50M (5%) dev fund, 4-year linear vesting
  • → 50M (5%) DAO/treasury, unlocked at genesis
  • → No Ownable — minter locked after one-time migration
  • → burnFromMiner() for challenge bonds + slash burns

MiningPool Autonomous

  • → Halving — 50 VOID → 25 → 12.5 → ... → 0.1 floor
  • → Elastic Mint — 0.8×–1.2× based on 10-sub quality avg
  • → Challenge/Slash — 6h window, 1 VOID bond, 20% slash
  • → Time-Lock — 7-day delay, 1% proposer quorum
  • → Pool Support — 2% fee, member shares, withdrawal
  • → ResultRegistry — on-chain scientific record
