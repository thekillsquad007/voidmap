Core Mechanics

◆

Halving

Block reward starts at 50 VOID and halves every 210,000 submissions (Bitcoin-style). Floor at 0.1 VOID. Predictable, transparent supply.

◆

Elastic Mint

Reward scales with network quality. Target quality = 75. High quality → 0.8x dampener (slow issuance). Low quality → 1.2x boost (attract more miners).

◆

Challenge / Slash

Any miner can challenge a submission within 6 hours. If quality is below floor, submitter loses 20% of reward. 50% to challenger, 50% burned.

◆

Time-Locked Governance

Param changes require 7-day delay + proposer must stake 1% of total miner-minted supply. No rug, no admin keys, no emergency switch.

◆

Anti-ASIC

5 layers: real data pipeline, dynamic ML models, 2s compute attestation, FPGA detection, architecture rotation. ASICs and emulated GPUs rejected.

◆

Pool Support

Anyone can run a pool. 2% fee deducted from pool submissions. Members tracked by share. Operator can withdraw accumulated fees anytime.

Data Pipeline

Step 1

Download

Real FITS files from MAST, cutout images from SDSS, alert streams from ZTF/Fink. No simulations.

Step 2

Process on GPU

Pre-trained models (AstroNet, Zoobot, Autoencoder) run inference. Outputs: predictions + confidence scores.

Step 3

Store on IPFS

Results uploaded to IPFS (Pinata or local daemon). CID stored on-chain. Fallback: sha256:<hash>

Step 4

Submit On-Chain

Pool operator submits submitWork(). VOID minted to miner. 2s min compute enforced.

  • ROCm AMD on Linux (PyTorch)

  • CPU Universal fallback

FPGA, emulated, virtual, software-renderer GPUs rejected at startup.

Anti-ASIC Defense (5 Layers)

1. Real Data Pipeline

HTTP downloads, variable FITS/JPEG sizes, Python preprocessing. Can't synthesize to fixed hardware.

2. Dynamic ML Models

PyTorch / ONNX with BatchNorm, Dropout, AdaptiveAvgPool. Variable input shapes. Architecture rotation.

3. Timing Attestation

MIN_COMPUTE_DURATION = 2s enforced both client and on-chain. Sub-2s results rejected.

4. Hardware Detection

FPGA, emulated, virtual, software-renderer GPUs rejected. Only consumer GPUs pass.

5. Architecture Rotation

anti_asic.py rotates CNN/Transformer/Mamba/ConvNeXT every 100 blocks. Weight perturbation.

  • 50M (5%) DAO/treasury, unlocked at genesis
